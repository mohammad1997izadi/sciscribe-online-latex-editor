## Overview

**SciScribe** is a cloud-based academic workspace that brings the everyday tools of scientific writing into one place: a collaborative online LaTeX editor and compiler with live PDF preview, journal and conference templates, a visual LaTeX table generator, a journal cover letter generator, a computer science supervisor finder, and a library of research-writing tutorials.

It is built by [Neural Revolution](https://sciscribe.dev/about/) around a single design goal: **protect the researcher's attention and remove friction between an idea and a publication-ready document.**

---

## The scientific case: why SciScribe exists

Research output is limited less by the number of ideas than by the cost of turning them into rigorous, correctly formatted, reproducible documents. Four well-documented problems motivate the platform.

### 1. Attention is the bottleneck, and interruptions are expensive
Scientific writing demands that arguments, data, notation, and citations be held in working memory at the same time. Studies of interruption and task switching in cognitive psychology and human-computer interaction consistently find that switching tasks carries a measurable cost in time and error rate, and that returning to a complex task after an interruption is slow. Cluttered interfaces, constant tool-hopping, and manual formatting chores all create these switches. SciScribe is designed so the writing area gets the most space, features appear when they are needed, and keyboard-driven workflows keep the researcher in flow.

### 2. LaTeX is the standard, but the syntax barrier is real
LaTeX remains the dominant format for mathematics-heavy and technical publishing because it produces precise, consistent, publisher-ready typesetting and treats equations as first-class content. The cost is complexity: tables, floats, packages, bibliographies, and compilation errors consume time that should go to the science, especially for early-career researchers. SciScribe lowers this barrier with intelligent autocomplete, error hints, a visual table generator, equation tools, and tutorials written for researchers.

### 3. Reproducibility begins with the manuscript
Plain-text, structured source documents are diffable, versionable, and archivable in a durable, open format. A cloud compiler produces consistent PDF output across devices and removes the "works on my machine" problem of local TeX installations, which supports the transparency expected of open and reproducible research.

### 4. Modern research is collaborative
Papers have multiple authors, theses have supervisors, and revisions are continuous. Emailing document versions invites conflicts and lost edits. SciScribe provides real-time co-authoring on a single source of truth, so teams spend time on content instead of merging copies.

## Features

### Write: collaborative online LaTeX editor and compiler
- Browser-based editor with **real-time compilation and live PDF preview**, with no TeX installation
- **Intelligent autocomplete** and error hints for LaTeX commands
- **Real-time collaboration** with co-authors and supervisors on the same project
- Project management for multi-file papers and theses
- **AI-assisted writing support**: grammar and spell checking that preserves LaTeX formatting, plus equation tools such as equation OCR (fair-usage limits apply to AI features)

### Format: visual LaTeX table generator
- Build tables visually and export clean LaTeX; **import from CSV or spreadsheets**
- Merge and split cells, control borders, header styles, colors, and alignment
- Generates `table` / `tabular` output and **identifies the required packages** (for example `tabularx`, `array`) in the generated code
- Free to use at [sciscribe.dev/table-generator](https://sciscribe.dev/table-generator/)

### Start: journal, conference, and academic templates
- Official-style templates for **journals and conferences** (IEEE, ACM, Springer, Elsevier and more), academic CVs, statements of purpose, and cover letters
- Open a template directly in the editor and start writing
- Browse at [sciscribe.dev/latex-template](https://sciscribe.dev/latex-template/)

### Submit: journal cover letter generator
- Produce a professional journal submission cover letter in minutes
- [sciscribe.dev/cover-letter/paper-submission](https://sciscribe.dev/cover-letter/paper-submission/)

### Plan: computer science supervisor finder
- Explore CS faculty at universities in Belgium, the Netherlands, and Canada by research area and field
- [sciscribe.dev/phd-finder](https://sciscribe.dev/phd-finder/)

### Learn: academic tutorials
- Practical guides on LaTeX, research writing, tables, packages, bibliographies, and thesis structure
- [sciscribe.dev/tutorial](https://sciscribe.dev/tutorial/)

## Getting started

1. Go to **[sciscribe.dev](https://sciscribe.dev)** and [create an account](https://sciscribe.dev/login/).
2. Start a new project, or open a [journal or conference template](https://sciscribe.dev/latex-template/).
3. Write your `.tex` source and review the compiled PDF as you type.
4. Use the [table generator](https://sciscribe.dev/table-generator/) whenever you need a table and paste the LaTeX into your document.
5. Invite co-authors to collaborate in the same project.

## Design principles

| Principle | In practice |
|---|---|
| **Focus first** | Maximum space for writing, minimal chrome, features appear when needed |
| **Keyboard-friendly** | Shortcuts and context-aware completion for fast, uninterrupted editing |
| **Welcoming to beginners, powerful for experts** | Guidance and tutorials without limiting advanced use |
| **Standards-aligned** | Output is standard LaTeX, portable to any other editor or compiler |
| **One connected workspace** | Writing, formatting, templates, and planning tools that work together |
